## 📐 Overview & Layout Architecture

This project uses a compact, grid-based card layout for an intuitive calculation interface:

| Section | Key Features & Functionality |
| :--- | :--- |
| **Display Screen** | Dark high-contrast screen area showing real-time inputs and results |
| **Operators Row** | Color-coded math action keys (`+`, `-`, `*`, `/`) for arithmetic operations |
| **Number Grid** | Standard 10-key numeric layout (`0`-`9`) with decimal point support |
| **Control Keys** | Dedicated clear button (`C`) and equal button (`=`) for evaluation |

---

## ✨ Features

* ⚡ **Instant Arithmetic:** Evaluates mathematical expressions with instant display feedback.
* 🛡️ **Error Handling:** Features built-in `try...catch` safety checks to handle invalid syntax gracefully.
* 🎨 **Color-Coded Controls:** Vibrant visual separation for numbers, arithmetic operators, clear function, and execution buttons.
* 📐 **CSS Grid Layout:** Structured key arrangement built using CSS Grid for perfect alignment.
